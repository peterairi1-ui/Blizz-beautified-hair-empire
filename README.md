Blizz Beautified Hair Empire

E-commerce hair store with a customer storefront and an admin dashboard.

Live site: https://blizzbeautified.com

 Features
- Product catalogue with image uploads
- Customer accounts and secure JWT login
- Shopping cart and orders
- Contact form and gallery
- Admin dashboard for managing products and orders

 Tech stack
React, Node.js, Express, MongoDB, Cloudinary

 Run it locally
1. Copy `backend/.env.example` to `backend/.env` and fill in your own values
2. In the `backend` folder, run `npm install` then `npm start`
3. In the `frontend` folder, run `npm install` then `npm run dev`
